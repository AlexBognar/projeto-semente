# Projeto Semente

## Objetivo

Criar um protótipo para validar o loop principal do jogo.

**Pergunta principal:** \> É divertido explorar, coletar recursos,
craftar e expandir uma pequena base?

------------------------------------------------------------------------

## Stack

-   **Engine:** Godot
-   **Linguagem:** C#
-   **Plataforma:** PC
-   **Estilo:** 2D Top-Down
-   **Arte:** Placeholders (formas simples ou assets gratuitos)

------------------------------------------------------------------------

## Core Loop

Explorar

↓

Coletar recursos

↓

Retornar à base

↓

Craftar ferramentas

↓

Construir estruturas

↓

Explorar novamente

------------------------------------------------------------------------

## Escopo do Protótipo

### Mundo

-   Pequeno mapa feito à mão
-   Árvores
-   Pedras
-   Arbustos
-   Pequenas áreas abertas

### Jogador

-   Movimento
-   Colisão
-   Inventário simples

### Recursos

-   Madeira
-   Pedra
-   Fibra
-   Carne
-   Couro

### Animais

Desde a primeira versão existirão animais simples.

Características: - Caminham aleatoriamente. - Não atacam. - Não possuem
IA complexa. - Podem ser abatidos. - Fornecem recursos (carne e couro).

O objetivo é apenas validar o loop de exploração e coleta.

### Craft

-   Machado
-   Picareta
-   Bancada de trabalho

### Construção

-   Bancada
-   Cabana simples

### Sobrevivência

Não haverá: - fome - sede - temperatura

No futuro, comida servirá como **buff**, e não como obrigação.

### Combate

Sem combate contra inimigos nesta fase. Os únicos alvos serão animais
neutros.

# Regras do Projeto

1.  Não trocar de engine.
2.  Não trocar de linguagem.
3.  Não adicionar novas mecânicas antes da atual estar funcionando.
4.  Toda nova ideia vai para o Estacionamento de Ideias.
5.  O objetivo é terminar um protótipo, não um jogo completo.
